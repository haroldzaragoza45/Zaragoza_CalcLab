# CalcLab — DCIT 26 Laboratory 1

A responsive calculator website built with **React + Tailwind CSS + Vite**.

## Requirements covered

- React components and application logic
- Tailwind CSS responsive layout and styling
- Calculator display
- Number buttons 0–9
- Addition, subtraction, multiplication, division
- AC/Reset and backspace
- Equals button
- React state and event handling
- Dynamic calculations
- Keyboard support
- Divide-by-zero / invalid expression handling
- Responsive design for mobile and desktop
- Instructions / user guide
- Supported operations section
- Button press animation

## Run locally

1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Push the project to GitHub, import the repository in Vercel, and use:

- Build command: `npm run build`
- Output directory: `dist`

No environment variables are required.
